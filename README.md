# 暖窝窝 🏠

> 把小家，慢慢过好。

暖窝窝是一款家庭家务协作与生活改善工具。目前主分支为 **V0.5 本地体验版**，历史 V0.4 保存在 `archive/v0.4` 分支。

## 使用方式

下载仓库 ZIP 并**解压**，保持 `index.html` 与 `v05.js` 在同一文件夹后，用浏览器打开 `index.html`。所有演示数据保存在**当前浏览器的 localStorage**，并非云端。

## 当前已有

- 五项预置家务：更换床单被套、清洁地面、清洁马桶、清理猫砂盆、清洗猫咪饮水机。
- 新增家务，修改已有家务的名称、责任人、周期类型、间隔天数和下次计划日期。
- 家务完成、计时、补录、暂停和日历记录。
- 家庭改善想法、基础统计与 JSON 数据导入/导出。

## 重要限制

- **没有账号系统或云数据库**：在不同设备上打开时不会自动同步数据。
- **没有系统推送通知**，也没有经过华为 Pura X / HarmonyOS 7 实机完整测试。
- 本地演示版本中的历史修改、计划重算、设备和保洁计时等场景仍需完善。
- 请勿把真实家庭数据、备份 JSON、密码、访问令牌等提交到这个公开仓库。

## 计划中的功能

1. 家庭创建、成员邀请、跨设备数据同步和访问权限控制。
2. 完整的重复周期调度、历史变更审计与冲突处理。
3. 人工劳动、机器人运行、外部保洁服务分类统计。
4. 通知提醒及鸿蒙 7、HyperOS、Windows、macOS 适配验证。

## 项目说明

当前为单文件 HTML/CSS/JavaScript 演示项目，无需构建或安装依赖。

代码公开不代表个人家庭数据应该公开。未来接入云端时，必须在正式上线前配置身份验证、数据库权限规则及安全的密钥管理。

## 版本与回退

- V0.5（当前版）：[main 分支](https://github.com/Sunny-sunny163/nuanwowo/tree/main)
- V0.4（存档版）：[archive/v0.4 分支](https://github.com/Sunny-sunny163/nuanwowo/tree/archive/v0.4)
- 可在 GitHub 分支切换器选择旧版，也可以下载每个分支的 ZIP 解压测试。
- 升级前在“家庭 → 导出数据”备份 JSON；旧版浏览器本地数据不会被刻意删除，但**不同浏览器或不同访问地址不保证自动共享数据**。
- 建议测试时为旧版与新版分别使用不同浏览器配置，并各自导入同一份备份，避免使用同一个 localStorage 空间导致测试互相影响。

## V0.5 变更

- 保留 V0.4 家务和任意日期范围工时统计的现有界面。
- 新增一次家务由**两位成员分别记录人工分钟数**；图表按参与人拆分汇总。
- 机器人 / 保洁运行时长与家庭成员准备、协助工时分开统计。
- 在“日历”选择有执行记录的日期后，支持修改或撤销该记录。
- 保存执行记录操作审计；修正同日额外执行对重复周期的影响。
- 保留原有本地导出/导入格式；没有上线云同步。

**已知限制**：固定日历周期仍需要扩展成每周/每月规则；跨任务保洁服务会话尚未实现；部分历史补录与人工改期冲突需要进一步严格校验。现阶段仍属测试版，建议保留备份。
